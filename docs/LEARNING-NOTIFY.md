# 좋은 결과물 → SOP 자동 보완 · 이메일 알림

## 1. SOP 자동 보완

### 흐름
```
👍 좋은 예 / 👎 아쉬운 예 / ✍️ 사람이 고친 뒤 승인 / 📈 성과 좋은 콘텐츠
        ↓ (학습 재료: 그 순간의 산출물 스냅샷 + 이유 메모)
단계별 미반영 재료가 '제안 기준'(기본 3개) 이상
        ↓ 👍 직후 또는 매일 18시
AI 가 공통 패턴을 찾아 "기존 SOP 대비" 줄 단위 변경안 작성 (추가 / 수정 / 삭제 + 근거 예시 번호)
        ↓
[제안만] 내가 변경별로 체크·문구 수정·최종 md 직접 다듬기 → 반영 / 거절
[자동]   근거 2개 이상인 추가·수정은 즉시 반영, 삭제·금지 항목 변경은 제안으로 남김
        ↓
SOP 변경 이력 + 학습 이력에 기록 · 메일 알림 · 언제든 "되돌리기"
```

### 학습 재료를 만드는 4가지 방법

| 방법 | 어디서 | 메모 |
|---|---|---|
| 👍 좋은 예 | 작업대 (또는 "승인 + 👍") | 메모란에 **좋은 이유**를 구체적으로 — 제안의 근거가 됨 |
| 👎 아쉬운 예 | 작업대 | 메모 필수. "피해야 할 것"의 근거 |
| ✍️ 수정 예 | 자동 — AI 산출물을 직접 고친 뒤 승인하면 원본/최종본 차이를 저장 | 설정에서 끌 수 있음 |
| 📈 성과 | 작업 효율 → 콘텐츠별 "👍 학습" | 조회·신청·전환 수치가 메모로 붙음 |

에이전트(Claude Code·Codex)에서는 "이거 좋다, 저장해" → `tpf-learn` 스킬이 `tpf good <id> <step> --note …` 를 실행합니다.

### 기존 SOP 를 지키는 장치

- AI 는 SOP 전체를 다시 쓰지 않고 **줄 단위 변경만** 제안합니다 (`lib/sop-merge.ts`).
- 수정·삭제는 기존 줄을 정확히 지목해야 하고, 그 사이 SOP 가 바뀌어 줄을 못 찾으면 **충돌**로 표시하고 건너뜁니다.
- 금지 표현이 들어간 변경은 버립니다. 금지 항목 변경·삭제·근거 1개짜리 변경에는 ⚠ 경고가 붙고 기본 체크가 꺼져 있습니다.
- 같은 내용이 이미 있으면 추가하지 않습니다. 새 학습은 `집중 포인트` 맨 위에 날짜와 함께 들어갑니다.
- 학습에 쓴 재료는 '반영됨'으로 표시되어 같은 재료로 반복 제안하지 않습니다(거절해도 동일).

### 수동 조절

| 하고 싶은 것 | 방법 |
|---|---|
| 변경 일부만 반영 | 제안 카드에서 체크 해제 |
| 문구를 고쳐서 반영 | 변경별 입력란 수정 |
| 최종 SOP 를 손으로 다듬어 반영 | "반영 후 SOP 미리보기 · 직접 다듬기"에서 편집 → 반영 |
| 반영 취소 | 학습 이력 → 되돌리기 (이후 SOP 를 또 고쳤다면 변경 이력에서 복원) |
| 잘못 고른 재료 빼기 | 학습 재료 목록 → 삭제 |
| 지금 바로 제안 | "지금 SOP 제안 만들기" (재료 1개 이상) |
| 학습 방식·기준 | 설정 → 🧠 SOP 학습 (제안만 / 자동 / 끔, 제안 기준 개수, 수정 예 수집) |

## 2. 이메일 알림

### 설정
1. Vercel 환경변수 — 둘 중 하나
   - **Resend**: `RESEND_API_KEY`, `EMAIL_FROM` (예: `오늘의 정책자금 <noti@내도메인>` — Resend 에서 도메인 인증 필요)
   - **SMTP**(예: Gmail): `SMTP_HOST=smtp.gmail.com` `SMTP_PORT=465` `SMTP_USER=보내는주소` `SMTP_PASS=앱 비밀번호` (Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호)
2. 하루 요약용 `CRON_SECRET` (임의 문자열). `vercel.json` 의 크론이 매일 09:00 UTC = 18:00 KST 에 `/api/cron/daily` 호출
3. 관리자 → 설정 → 📧 이메일 알림: 받는 이메일 입력 → 알림 종류 체크 → 저장 → "테스트 메일"

### 알림 종류와 내용

| 종류 | 언제 | 메일에 들어가는 것 |
|---|---|---|
| 결정 필요 | 사람이 결정할 산출물이 나왔을 때 | 일의 흐름(10단계 진행 막대) · 이번에 끝난 일 정리 · 규칙 검사 · AI 의견·질문 · 다음 할 일 · 작업대 버튼 |
| 단계 완료 | AI 검수·자동으로 통과했을 때 | 위와 같음 (작성 제공자·시도·소요 포함) |
| 실패 | 단계·렌더·업로드 실패 | 오류 내용 · 다음 할 일 |
| 영상 렌더 완료 | 워커 렌더 끝 | 영상 길이 · 영상 링크 · 썸네일 |
| 게시 완료 | 업로드·공개 끝 | 유튜브·인스타 결과 · 댓글 고정 안내 |
| SOP 학습 제안 / 반영 | 제안 생성·반영 시 | 요약 · 변경 목록(삭제는 취소선, 추가는 초록) · 근거 · 경고 |
| 하루 요약 (18시) | 매일 | 결정 대기 · 오늘 끝난 일(콘텐츠별 단계 흐름) · 진행 현황 막대 · 오늘 게시 · 신청 수 · SOP 학습 현황 |

"이번에 끝난 일"은 단계마다 다르게 정리됩니다 — 조사(주제·한도·금리·마감·근거·확인 필요), 기획(훅·후보·구성), 대사(내레이션 전문·분량), 이벤트(이벤트명·혜택·마감 근거), 랜딩(헤드라인·버튼), 디자인(장면 그래픽), 카피(제목·댓글·캡션), 정보글(제목·메타·분량), 렌더(길이·영상), 게시(링크). 추가 AI 호출 없이 산출물에서 바로 만듭니다.

알림 메일 발송이 실패해도 제작 공정은 멈추지 않습니다. 결과는 설정 → 최근 발송 기록에 남습니다.

### 메일이 너무 많으면
"가능한 곳까지 자동 진행" 한 번에 여러 단계가 끝나면 단계마다 메일이 갑니다. "단계 완료"를 끄고 "결정 필요·실패·게시·하루 요약"만 켜 두면 꼭 필요한 것만 받습니다.
