# 영상 디자인 — 언론사 템플릿 · 스타일 · Claude 모션 · 자막

## 1. 언론사 템플릿 (기본)
새로 만드는 디자인은 `news` 템플릿으로 나옵니다. 예전 디자인은 `classic`으로 남고, 디자인 단계를 다시 돌리거나 편집기에서 스타일을 적용하면 바뀝니다.

| 레이아웃 | 쓰는 곳 |
|---|---|
| breaking | 첫 장면. 속보 태그와 큰 헤드라인 |
| headline | 핵심 문장 한 줄 |
| stat | 숫자 카운트업. **출처 필수** |
| list | 요점 2~4개 |
| compare | 둘 비교. 항목은 `라벨\|내용` 정확히 2개 |
| quote | 공고문·관계자 인용 |
| document | 공문서 카드 (기관·문서명·발췌) |
| timeline | 일정. 항목은 `날짜\|내용` |
| cta | 마지막 장면. 신청 안내 |

화면 요소: 채널 표시(bug), 날짜, 진행선, 티커(선택), 격자 배경, 출처 줄. 안전 영역은 y 290~1360입니다.

## 2. 영상 스타일 (`/admin/styles` — 왼쪽 메뉴 [영상 스타일])
- **기본 프리셋 3종**: 언론사·네이비(기본), 언론사·지면(화이트 · 명조 제목), 언론사·속보(블랙 · 빨강 · 티커).
- **레퍼런스로 새 스타일 만들기**
  - 입력: 마음에 드는 채널의 캡처(최대 6장, 끌어놓기·붙여넣기 가능), 유튜브 쇼츠 링크, 또는 [참고 영상]에서 분석이 끝난 영상.
  - 분석: Claude(작업 `style`, 비전)가 색, 폰트·굵기, 자막 모양, 화면 구성 규칙, 모션 성향을 뽑습니다.
  - 확인과 저장: 샘플 영상(레이아웃 9종)으로 바로 미리 본 뒤 저장합니다.
  - 유튜브 링크는 썸네일만 보여서 대략적입니다. 정확하게 하려면 참고 영상 프레임을 쓰세요.
  - 인스타그램은 로그인이 필요해서 캡처로 올려야 합니다.
- **기본으로 지정**: 이후 디자인 단계가 그 스타일의 규칙·색·폰트·자막으로 영상을 만듭니다.
- **콘텐츠마다 바꾸기**: 편집기 [스타일·전체] 탭에서 다른 스타일을 고를 수 있습니다.
- **편집기에서 저장**: 편집기에서 다듬은 디자인도 [스타일로 저장]하면 재사용할 수 있습니다.

## 3. Claude 모션 (편집기 [모션] 탭)
- 장면마다 "Claude 에게 모션 요청" 칸에 원하는 연출을 적습니다. 예: "60억 숫자를 크게 카운트업하고 밑줄이 그어지게".
- Claude(작업 `motion`, Opus)가 레이어를 만들어 줍니다.
  - 레이어 종류: text, tag, box, line, highlight, counter, bar, image, emoji.
  - 등장·퇴장: fade, slide(상하좌우), scale, pop, wipe(4방향), blurIn, typewriter, countUp, grow. 시작 시점, 길이, 이징을 정합니다.
  - 그 밖에 키프레임, 반복, 앞뒤 순서(z)를 지정합니다.
- 레이어는 목록에서 바로 고치거나 미리보기에서 끌어 옮길 수 있습니다. JSON으로 직접 편집해도 됩니다.
- 디자인 단계 AI도 같은 레이어 규칙으로 장면마다 모션을 넣습니다.

## 4. 자막 (편집기 [자막] 탭)
- **전체 설정**
  - 모양: 하단 자막 / 띠 / 박스 / 글자만
  - 라벨 탭과 색
  - 글꼴과 굵기 (해당 글꼴에 실제로 있는 굵기만 표시)
  - 정렬, 크기(px), 글자색·강조색
  - 바탕색과 투명도, 여백, 모서리, 왼쪽 강조 막대
  - 외곽선, 그림자, 줄간격, 자간, 최대 폭, 바닥에서 높이
  - 애니메이션: 없음 / 페이드 / 팝 / 슬라이드 / 와이프 / 단어별 / 가라오케
- **장면별 덮어쓰기**: 색, 바탕, 굵기, 정렬, 숨김.
- **강조**: 장면의 강조 단어(emphasis)가 자막에서도 강조색으로 나옵니다.

## 5. 글꼴
- 언론·공식: Pretendard, Noto Sans KR, Noto Serif KR, IBM Plex Sans KR
- 고딕: Gothic A1, 나눔고딕
- 명조: 함렛, 나눔명조, 고운바탕
- 제목: 검은고딕, 도현, 가석, 해바라기
- 개성: 주아, 고운돋움, 동글, 나눔손글씨 펜

렌더 워커는 `worker/scripts/fonts.sh`로 굵기별 파일을 받아 씁니다.
