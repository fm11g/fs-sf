# 채널 성과 → 최종 점수 → 새로움 유지 편성

## 매일 흐름 (06:10 KST, GitHub Actions)

```
① 채널 수집      유튜브·인스타에 올라간 영상(최근 60일)의 조회·좋아요·댓글·공유·저장·시청 유지 + 댓글 본문
② 분석·점수      댓글 분석(요약·질문·요청·신청 의향·품질) · 형태 분류(주제 분류·각도·훅·구성·대상) · 최종 점수 1~5
③ 성과 → 학습    7일 지나 확정된 공장 콘텐츠는 기획·대사·카피를 성과 점수로 평가 → SOP 학습·참고 예시에 반영
④ 편성          점수 × 새로움으로 7일 편성표 갱신 (배정·고정 슬롯 유지)
⑤ 제작          새 콘텐츠가 오늘 슬롯을 받고 → 조사·기획 프롬프트에 슬롯과 "최근과 겹치지 말 것"이 들어감
```
관리자 [채널 성과] "지금 수집", [편성표] "다시 편성"으로 언제든 수동 실행.

## 1. 채널 연결

관리자 → **채널 성과** → 유튜브 채널 링크(`https://www.youtube.com/@핸들`)·인스타 계정 링크 저장.

| 플랫폼 | 필요한 것 | 얻는 지표 |
|---|---|---|
| 유튜브 (기본) | GitHub Secret `YT_API_KEY` (YouTube Data API 키) 또는 기존 업로드용 OAuth | 조회·좋아요·댓글 수·댓글 본문 |
| 유튜브 (권장) | [설정 → 유튜브 채널 연결]을 **다시** 해서 새 `YT_REFRESH_TOKEN` 저장 (Analytics 권한 추가) | + 공유·평균 시청 비율·평균 시청 시간·구독 증가 |
| 인스타 | 기존 `IG_USER_ID`·`IG_ACCESS_TOKEN` + insights·댓글 권한 | 좋아요·댓글 + 조회(views)·도달·저장·공유·평균 시청 시간·댓글 본문 |

- 유튜브는 3분 이하 영상(Shorts)만 집계합니다.
- 인스타 토큰의 계정과 설정한 링크가 다르면 경고를 남기고 토큰 계정 기준으로 수집합니다.
- 지원 안 되는 지표가 있으면 그 지표만 빼고 수집합니다(실패 경고는 [채널 성과] 분석 결과에 표시).

## 2. 최종 콘텐츠 점수 (1~5)

**내 채널 영상끼리 비교한 백분위**입니다. 채널이 작아도 "우리 채널 기준으로 잘 됐는지"가 나옵니다.

| 요소 | 계산 | 기본 가중치 |
|---|---|---|
| 조회 | 조회 ÷ (1 + ln(1 + 경과일, 최대 14일)) — 갓 올린 영상이 불리하지 않게 나이 보정 | 35% |
| 참여 | (좋아요 + 댓글 + 저장) ÷ 조회 | 20% |
| 공유 | 공유 ÷ 조회 | 15% |
| 댓글 | 댓글 품질(분석 1~5) × ln(1 + 댓글 수) × (1 + 신청·문의 의향 비율) | 10% |
| 시청 유지 | 평균 시청 비율(유튜브) / 평균 시청 시간(인스타) | 10% |
| 신청 전환 | 랜딩 신청 ÷ 랜딩 조회 (공장 콘텐츠, 조회 20건 이상) | 10% |

- 값이 없는 요소는 빼고 나머지 가중치로 다시 나눕니다.
- 성숙도: 48시간 미만 **잠정** · 7일 미만 **집계 중** · 7일 이상 **확정**. 비교 기준은 24시간 넘은 영상만.
- 확정된 공장 콘텐츠는 기획·대사·카피 단계에 성과 평가(출처 `performance`, 태그 `성과:조회상위`·`성과:공유하위` …)로 들어가 **사람 평가와 별도로** SOP 학습·참고 예시에 쓰입니다.
- 가중치는 설정 `perf_weights` 로 바꿀 수 있습니다.

## 3. 편성 — 선별 · 흐름 · 순서

### 선별 (형태별 후보 점수)
형태 5가지(주제 분류·각도·훅·구성·대상)마다 값별로
`후보 점수 = (1 − 새로움 강도) × 성과 + 새로움 강도 × 새로움 − 반복 감점`
- **성과**: 그 형태 영상들의 평균 최종 점수를 채널 평균 쪽으로 당긴 값(영상 1~2개짜리 우연에 쏠리지 않게)
- **새로움**: 마지막 사용 이후 경과일 (쿨다운 × 2일이면 최대). 한 번도 안 쓴 값은 중간값 + 미검증 감점 → 탐색은 실험 슬롯에서
- **반복 감점**: 같은 주 편성 안에서 이미 쓴 값

### 순서·흐름 (반복 규칙)
- 같은 주제 분류 이틀 연속 금지 · 같은 각도는 쿨다운(기본 3일) 안에 재사용 금지
- 같은 훅 3연속 금지 · 같은 구성 연속 금지 · 한 주 안에 같은 주제 분류+각도 조합 재사용 금지
- 주 1편 이상 **실험 슬롯**(검증 안 된 각도·구성·훅) — 실험 비율로 조정
- AI 편성 PD가 리듬(강한 훅 → 정보형 → 사례로 환기 → 마감 정리)과 시청자 요청을 반영해 제목 아이디어·훅 예시·이유·흐름을 붙입니다. AI 안이 규칙을 어기면 계산된 편성으로 되돌리고 경고를 남깁니다.

### 기획 연동
- 새 콘텐츠는 오늘 슬롯(없으면 가장 가까운 미배정 슬롯)을 받습니다.
- **조사**: 슬롯의 주제 분류에 맞는 공고 우선 + 시청자 요청 + 최근 6편과 겹치지 말 것
- **기획**: 슬롯의 각도·훅·구성 사용 + 같은 분류에서 점수 높았던 영상의 형태 참고(내용 반복 금지)
- 규칙 검사에 경고: 최근 주제와 겹침 · 직전과 같은 주제 분류/각도/구성 · 같은 훅 3연속 · 편성 슬롯과 다름

### 수동 조절 ([편성표])
슬롯별 형태 변경 · 순서 ↑↓ · 고정(다시 편성해도 유지) · 다시 편성 · 새로움 강도(0 성과 우선 ~ 1 새로움 우선, 기본 0.35) · 실험 비율 · 쿨다운 · 편성 끄기.

## 4. 데이터 저장
- GitHub `data/channel/YYYY-MM-DD.json` (일별 영상 성과·댓글 분석·형태), `data/editorial/…json` (편성표)
- 구글 시트 탭 `channel_posts`(일별 영상 성과) · `editorial`(편성표)
- 분류 목록은 `lib/editorial-taxonomy.ts` 한 곳에서 관리 (바꾸면 프롬프트·화면·통계가 함께 바뀜)
