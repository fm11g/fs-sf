# 06. 디자인·모션

## 목적
대사의 핵심 정보를 언론사처럼 공식적이고 신뢰감 있게 보여 준다. 화려함보다 정확·단정·출처.

## 집중 포인트
- 스타일 프리셋을 따른다: 색·폰트·굵기·자막 모양·화면 장식은 공장이 프리셋으로 고정 → 장면 구성·문구·레이어에 집중
- 첫 장면은 breaking(속보·단독·공고 태그) 또는 headline(기사 제목 카드). 마지막은 cta
- 한 장면 한 메시지. 제목은 한 줄 10자 안팎, 최대 2줄. 왼쪽 정렬
- 숫자가 나오는 장면(stat·list·document·timeline)은 source(기관 + 문서명)를 반드시 단다
- 일정은 timeline(마지막 = 마감), 공고 내용은 document(형광펜 = emphasis), 대비는 compare
- 모션은 절제: 마스크 리빌·와이프·슬라이드·카운트업. 레이어는 꼭 필요한 장면에만 0~4개, 0.6초 이후 등장
- 레이어는 안전 영역(y 290~1360, x 72~984) 안에. 레이아웃 글자와 겹치지 않게

## 체크리스트
- [ ] 모든 대사 장면에 디자인이 있다 (id 일치)
- [ ] 숫자 장면에 source 가 있고, 숫자가 조사 산출물과 같다
- [ ] 이모지·감탄·과장 표현 없음
- [ ] 제목 줄이 넘치지 않는다 (한 줄 11자 이하)
- [ ] 레이어가 안전 영역 안이다

## 금지
- 조사에 없는 숫자·기관·날짜
- 장면마다 다른 색을 쓰기 (프리셋 색 밖)
- 튀는 효과(pop·blink)를 반복해서 쓰기

## 사람이 결정할 것
- 어떤 스타일 프리셋을 쓸지 ([영상 스타일]에서 기본 지정 또는 작업대·편집기에서 콘텐츠별 선택)
- 편집기에서 자막·레이어 세부 조정 후 다시 렌더
