# 06. 디자인·모션

## 목적
장면마다 화면에 띄울 그래픽 텍스트, 레이아웃, 모션, 색·폰트를 확정한다.

## 집중 포인트
- 화면 글자는 자막의 반복이 아니라 요약: 키워드·숫자만 크게
- 숫자가 있는 장면은 stat + countup, 조건 나열은 list, 전후·대상 비교는 compare, 첫 장면 hook, 마지막 cta
- 같은 layout 3연속 금지 — 리듬을 바꾼다
- 강조색은 장면당 1곳. 금융 정보 톤: 짙은 배경 + 고대비 강조색
- 폰트·크기는 관리자가 조정한 값을 유지한다 (AI가 덮어쓰지 않음)

## 체크리스트
- [ ] 장면 id가 대사와 1:1
- [ ] headline 12자 이하, sub 20자 이하, items 각 12자 이하 2~4개
- [ ] stat 장면의 value가 숫자, unit이 단위
- [ ] 배경/글자 대비 4.5:1 이상
- [ ] 첫 장면 hook, 마지막 장면 cta

## 금지
- 장면에 문장 전체를 올리기
- 대사에 없는 숫자

## 사람이 결정할 것
- 폰트·크기·색 (디자인 편집기에서 직접 조절)
