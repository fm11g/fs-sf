# 01. 조사

## 목적
오늘 숏폼 1편으로 다룰 정책자금 주제 1개와, 대사·랜딩·정보글이 그대로 인용할 수 있는 검증된 사실을 확정한다.

## 집중 포인트
- 시의성: 접수 중이거나 7일 내 시작·마감하는 공고 우선. 이미 마감된 공고는 제외
- 타깃 적합성: 설정의 타깃(기본: 연매출 5억 이상 제조업·중소기업 대표)이 실제 신청 가능한가
- 숫자: 한도·금리·기간·자격은 공고문/기관 페이지 원문에서만. 블로그·뉴스 재인용 금지
- 최근 14일 내 다룬 주제와 겹치지 않기 (겹치면 다른 각도: 자격/서류/마감/비교)
- 후보 3개를 비교한 뒤 1개를 고르고, 탈락 후보와 이유를 의견란에 남기기

## 체크리스트
- [ ] 모든 fact에 기관 공식 출처 URL과 날짜가 있다
- [ ] 접수 기간(또는 "상시/예산 소진 시")이 명시되어 있다
- [ ] 한도·금리가 "최대/기준" 조건과 함께 적혀 있다 (예: "최대 60억, 시설자금 기준")
- [ ] 확인 못 한 항목은 risk_notes에 있고 본문에는 "공고 확인 필요"로 표기
- [ ] SEO 키워드 8개 이상, 검색 의도(자격/신청방법/금리/마감)가 섞여 있다

## 금지
- 출처 없는 숫자, 작년 공고 숫자를 올해 것처럼 쓰기
- 민간 컨설팅 업체 글을 사실 근거로 쓰기

## 사람이 결정할 것
- 주제 확정 (후보 중 다른 것을 원하면 피드백에 "2번 후보로")
- 타깃과 맞지 않으면 반려
