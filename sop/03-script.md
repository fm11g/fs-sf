# 03. 40초 대사

## 목적
AI 성우가 그대로 읽을 내레이션과 화면 자막을 확정한다. 이후 이벤트·랜딩·카피·정보글이 모두 이 대사를 기준으로 맞춘다.

## 집중 포인트
- 말하듯이: 한 문장 20자 안팎, 조사 생략 가능, 한자어·공문서 표현을 일상어로
- 숫자는 귀로 들어도 이해되게: "육십억" 대신 "최대 60억 원"처럼 단위 붙이기, 한 문장에 숫자 1개
- 첫 문장은 기획의 chosen_hook 그대로 또는 더 짧게
- 조건·예외는 한 번만: "업력 3년 이상이면" 수준. 세부는 랜딩으로 넘긴다
- 마지막 문장: 고정 댓글/프로필 링크에서 "내 조건 확인" 유도

## 체크리스트
- [ ] 내레이션 총 210~250자 (공백 제외)
- [ ] 자막 한 컷 14자 이하, 내레이션과 내용 일치, 누락 없음
- [ ] 조사 단계 facts에 없는 숫자·기관명이 없다
- [ ] 금지 표현 없음, 승인·한도 보장 뉘앙스 없음
- [ ] 소리 내어 읽었을 때 숨 쉴 곳이 장면마다 있다

## 금지
- "~하실 수 있습니다"의 반복, 영어 약어 남발
- 자막에 말줄임표·이모지

## 사람이 결정할 것
- 어조: 단호/친근 (피드백에 한 단어로)
- 대사가 확정되면 하위 단계 전부가 이것을 따르므로 여기서 사실관계를 최종 확인
