# 10. 업로드·공개

## 목적
유튜브 쇼츠와 인스타 릴스에 게시하고, 댓글에 카피+랜딩 링크를 달고, 랜딩과 정보글을 공개한다.

## 집중 포인트
- ★ 업로드가 끝나면 공장이 홈페이지에 자동 등록한다(정보글 발행 + 숏폼 코드 목적지). 상세 화면 [홈페이지 연동] 카드에 정보글 주소가 생겼는지 확인하고, 경고가 있으면 [홈페이지에 등록]
- 인스타 프로필 링크는 go.html?c=today&ch=igp 하나로 고정 — 항상 가장 최근 숏폼 정보글로 연결되고 인스타 DB 로 집계
- 게시 순서: 유튜브 업로드 → 유튜브 댓글 → 인스타 릴스 → 인스타 첫 댓글 → 랜딩 공개(/l/슬러그) → 홈페이지 정보글 발행 · 숏폼 코드 등록(자동)
- 게시 직후 사람 작업 1개: 유튜브 스튜디오에서 방금 단 댓글 "고정" (API 미지원)
- 게시 시간대: 설정한 스케줄 기준. 성과를 보고 SOP에 기록

## 체크리스트
- [ ] 렌더·카피·랜딩·정보글이 모두 승인 상태
- [ ] 랜딩 미리보기에서 신청 폼이 동작한다
- [ ] 유튜브 댓글 고정 완료
- [ ] 홈페이지 연동 카드에 정보글 주소 · 코드가 보인다
- [ ] 24시간 뒤 현황판·홈페이지 관리자 [유입 분석]에서 이 숏폼 DB 수 확인 → 배운 점을 해당 단계 SOP `집중 포인트`에 추가

## 금지
- 검수 안 된 영상의 자동 게시 (자동 업로드를 켜기 전 2주는 수동 권장)

## 사람이 결정할 것
- 게시 채널 선택 (유튜브/인스타)
