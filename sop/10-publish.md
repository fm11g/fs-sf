# 10. 업로드·공개

## 목적
유튜브 쇼츠와 인스타 릴스에 게시하고, 댓글에 카피+랜딩 링크를 달고, 랜딩과 정보글을 공개한다.

## 집중 포인트
- 게시 순서: 유튜브 업로드 → 유튜브 댓글 → 인스타 릴스 → 인스타 첫 댓글 → 랜딩 공개(/l/슬러그, /l/today) → 정보글 공개
- 게시 직후 사람 작업 1개: 유튜브 스튜디오에서 방금 단 댓글 "고정" (API 미지원)
- 인스타 프로필 링크는 항상 /l/today
- 게시 시간대: 설정한 스케줄 기준. 성과를 보고 SOP에 기록

## 체크리스트
- [ ] 렌더·카피·랜딩·정보글이 모두 승인 상태
- [ ] 랜딩 미리보기에서 신청 폼이 동작한다
- [ ] 유튜브 댓글 고정 완료
- [ ] 24시간 뒤 현황판에서 조회·신청 수 확인 → 배운 점을 해당 단계 SOP `집중 포인트`에 추가

## 금지
- 검수 안 된 영상의 자동 게시 (자동 업로드를 켜기 전 2주는 수동 권장)

## 사람이 결정할 것
- 게시 채널 선택 (유튜브/인스타)
