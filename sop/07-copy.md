# 07. 채널 카피

## 목적
유튜브 쇼츠 제목·설명·댓글, 인스타 릴스 캡션·첫 댓글을 확정한다. 링크는 시스템이 자동으로 넣는다({LINK}).

## 집중 포인트
- 유튜브 제목: 앞 20자 안에 대상+핵심 숫자. 40자 이내, 끝에 #shorts
- 유튜브 댓글(고정용): 1줄 요약 → 이벤트 한 줄 → 링크. 3줄 이내
- 인스타 캡션: 첫 줄(125자 안)이 전부라고 생각하고 쓴다. 링크는 클릭이 안 되므로 "프로필 링크"를 함께 안내
- 이벤트(04) 이름을 댓글·캡션에 그대로 사용 — 랜딩과 같은 단어
- 해시태그: 주제 3 + 대상 3 + 채널 고정. 무관한 인기 태그 금지

## 체크리스트
- [ ] 제목 40자 이하, 설명·댓글·캡션에 {LINK}가 각 1회
- [ ] 댓글·캡션의 이벤트명이 04와 같다
- [ ] 조사에 없는 숫자 없음, 금지 표현 없음
- [ ] 인스타 해시태그 15개 이하

## 금지
- 낚시성 제목 (영상에 없는 내용)
- 댓글에 링크만 덩그러니

## 사람이 결정할 것
- 제목 최종 선택
