# 05. 랜딩 문구

## 목적
랜딩 템플릿의 각 슬롯을 오늘 대사와 이벤트에 맞는 문구로 채워, 영상 → 랜딩 → 신청이 한 흐름으로 읽히게 한다.

## 집중 포인트
- 첫 화면(배지·헤드라인·서브): 영상 훅과 같은 단어를 써서 "아까 그 영상"임을 1초 안에 알게 한다
- 설득 순서: 공감(내 얘기다) → 핵심 정보 3가지(얼마/누가/언제까지) → 이벤트 혜택 → 신청 방법 → 불안 해소(비용·시간·심사 안내)
- 버튼 문구는 행동 + 얻는 것: "내 조건 무료 확인하기"처럼. "신청하기" 단독 사용 지양
- 글자수: 슬롯 최대치의 70~100%를 채운다. 너무 짧으면 레이아웃이 빈다
- 모바일 2줄 안에서 끊기도록 줄바꿈(\n) 위치를 의미 단위로

## 체크리스트
- [ ] 모든 슬롯이 채워졌고 최대 글자수 이하
- [ ] 헤드라인에 대사의 핵심 숫자 또는 대상이 있다
- [ ] 이벤트 슬롯 내용이 04 이벤트 산출물과 일치 (이름·혜택·마감)
- [ ] 버튼 문구가 화면마다 같은 행동을 가리킨다
- [ ] 금지 표현 없음, 조사에 없는 숫자 없음

## 금지
- 영상에 없던 새로운 약속
- 같은 문장을 여러 슬롯에 반복

## 사람이 결정할 것
- 미리보기(/l/슬러그)에서 줄바꿈·길이 확인
