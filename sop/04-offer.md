# 04. 이벤트·오퍼

## 목적
영상을 보고 들어온 사람이 랜딩에서 "지금 신청"할 이유를 만든다. 대사의 주제와 한 문장으로 이어지는 이벤트 1개를 확정한다.

## 집중 포인트
- 연결성: 영상 마지막 문장 → 이벤트 제목이 같은 말로 이어지게. 예) 영상 "내 조건 확인" → 이벤트 "○○자금 자격 10분 무료 진단"
- 혜택은 설정의 `제공 가능한 혜택` 안에서만 고른다. 주제에 가장 맞는 것 1개를 주력, 1~2개를 보조
- 긴급성은 사실에서만: 공고의 실제 접수 마감일, 예산 소진 공지. 없으면 긴급성 없이 "편의"로 설득
- 신청 허들 낮추기: 입력 항목 3개 이하, 소요 시간·비용 명시 ("전화 10분, 비용 없음")
- 신청 후 무슨 일이 일어나는지 3단계로 (신청 → 연락 → 결과 안내)

## 체크리스트
- [ ] 이벤트명에 오늘 주제(자금명 또는 대상)가 들어 있다
- [ ] 혜택이 모두 설정에 등록된 실제 제공 항목이다
- [ ] 마감 문구가 공고의 실제 날짜이거나, 없으면 비어 있다
- [ ] "승인", "확정", "보장" 류 표현이 없다
- [ ] 유의사항에 "심사에 따라 결정" 문구가 있다

## 금지
- 가짜 선착순·가짜 카운트다운·근거 없는 "오늘만"
- 수수료·성공보수 관련 언급을 임의로 만들기

## 사람이 결정할 것
- 이 이벤트를 실제로 운영할 수 있는지 (상담 인력·시간)
- 혜택 구성 변경
