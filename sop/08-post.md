# 08. SEO 정보글

## 목적
영상과 같은 주제를 검색으로 찾는 사람에게 답이 되는 사이트 글을 만들고, 글 끝에서 랜딩으로 보낸다.

## 집중 포인트
- 검색 의도에 먼저 답한다: 첫 문단 3문장 안에 "누가·얼마·언제까지"
- 제목: 핵심 키워드를 앞에, 32자 이내. 연도·월 포함 권장
- 구조: 지원 내용 → 신청 자격 → 신청 방법·일정 → 자주 놓치는 포인트 → 정리. 표 1개 이상
- 영상에서 생략한 세부(서류, 제외 대상, 금리 산정)를 여기서 채운다
- 이미지 자리 4곳, 대체텍스트에 키워드를 자연스럽게
- 마지막 문단에서 이벤트(04)를 한 번 소개하고 {LINK}

## 체크리스트
- [ ] 본문 2,000~3,000자, H2 5개 이상
- [ ] 메타 설명 80~120자, 키워드 포함
- [ ] 모든 숫자가 조사 facts와 일치, "참고 공고"에 출처 링크
- [ ] FAQ 3~5개가 실제 검색 질문 형태
- [ ] 금지 표현 없음

## 금지
- 키워드 나열, 같은 문장 반복
- 출처 없는 비교·순위

## 사람이 결정할 것
- 게시 전 사실관계 최종 확인 (기본값: AI 검수 후 통과)
