# 02. 기획

## 목적
40초 안에 "멈춤 → 이해 → 행동"이 일어나는 구성안과 훅을 확정한다.

## 집중 포인트
- 첫 2초 훅: 대상 호명 + 숫자 또는 손실 회피. 예) "제조업 대표님, 이번 주 금요일 마감입니다"
- 한 편에 메시지 하나. 공고 전체를 설명하려 하지 않는다 — 나머지는 랜딩·정보글이 담당
- 장면당 전달 포인트 1개, 6~8장면, 합계 38~42초
- 마지막 장면은 CTA: "내 조건으로 되는지"를 확인하게 만든다 (승인 약속 아님)
- 무드(urgent/calm/hopeful/serious)는 BGM 선택에 쓰이므로 주제 성격에 맞게

## 체크리스트
- [ ] 훅 후보 3개가 서로 다른 유형이다 (숫자형 / 질문형 / 손실형)
- [ ] 선택한 훅에 조사 단계에 없는 사실이 없다
- [ ] structure의 seconds 합이 38~42
- [ ] 2~3번째 장면 안에 "누가 받을 수 있는지"가 나온다
- [ ] 마지막 장면 role이 cta

## 금지
- 과장 훅 ("누구나", "무조건", "안 받으면 바보")
- 장면 하나에 숫자 3개 이상

## 사람이 결정할 것
- 훅 선택 (다른 후보를 원하면 피드백에 번호)
- 영상 각도: 마감 임박 / 자격 확인 / 금액 강조 중 무엇으로 갈지
