# 09. 음성·자막·BGM·렌더

## 목적
승인된 대사·디자인으로 40초 세로 영상(1080x1920)과 썸네일, 정보글용 이미지를 만든다. (GitHub Actions 워커가 수행)

## 집중 포인트
- 길이: 35~45초. 벗어나면 대사 글자수 또는 설정의 말 속도를 조정
- 음성: 숫자·기관명 발음. 어색하면 대사에서 한글 표기를 바꾼다 ("2.5%" → "이 점 오 퍼센트")
- 자막 타이밍: 음성보다 늦지 않게. 한 컷이 너무 길면 대사 단계에서 자막을 더 쪼갠다
- BGM: 내레이션을 가리지 않는 볼륨, 무드 일치
- 첫 프레임(썸네일)에 훅 문구가 읽히는가

## 체크리스트
- [ ] 총 길이 35~45초
- [ ] 발음 오류 없음
- [ ] 자막 잘림·줄넘침 없음
- [ ] 마지막 장면에 댓글·프로필 링크 안내가 보인다

## 금지
- 저작권 미확인 BGM

## 사람이 결정할 것
- 영상을 끝까지 보고 승인 (기본값: 사람). 고칠 것이 있으면 해당 단계(대사/디자인)를 수정 → 다시 렌더
